# ✦ Фойе

Своя главная SillyTavern вместо стоковой «Recent Chats» — в стиле «Графит и вино», как Life.

- **«Продолжить»** — большая карточка последнего (или закреплённого) чата: последний кадр из чата фоном, состав, место и время из шапки GC (или из Horae), концовка последнего поста — на чём остановились. Тап — открыть.
- **Недавние** — остальные чаты карточками: аватарка (у группы — её фото или коллаж), нормальное имя ветки вместо `2026-06-20@18h13m11s091ms`, концовка поста без HTML/JSON/CSS/плашек/think/заметок.
- **⋯** у любого чата: открыть, закрепить, своё название в Фойе (например «God Complex»), переименовать файл, удалить. Всё делают стоковые кнопки ST — Фойе их только жмёт.
- **Поиск** по чатам, **полка персонажей** (избранные первыми, тап — их последний чат), временный чат, «сколько чатов грузить».
- Поле ввода на главной спрятано (оно там всё равно открывает чат с ассистентом) — включается шестерёнкой.
- **Снимки.** Пока чат открыт, Фойе запоминает последний кадр, шапку и концовку поста (в настройках расширения, до 40 чатов) — поэтому на главной видно сцену, даже если последним сообщением в файле лежит лог телефона.

Ничего не шлёт модели, второго запроса к серверу не делает (берёт тот же ответ `/api/chats/recent`, что и ST).

## Установка

```
docker exec sillytavern sh -c 'cd /home/node/app/data/default-user/extensions && git clone -b foyer --single-branch https://github.com/clarawill137/LIFE foyer'
```

Потом обновить страницу.

## Обновление

```
docker exec sillytavern sh -c 'cd /home/node/app/data/default-user/extensions/foyer && git pull'
```

## Выключить

Расширения → ✦ Фойе → «Своя главная вместо стоковой».
