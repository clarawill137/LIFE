# ✦ Life

Личный хаб для SillyTavern в стиле «Графит и вино»: главы-комнаты, карта мира, персонажи и мир, всё поверх **Horae**.

- **Данные ведёт Horae** (время, место, кто в сцене, одежда, вещи, события, планы).
- **Летописец** — дешёвая модель после каждого поста (профиль подключения, по умолчанию как у костюмера Гардероба): чинит инвентарь Horae (склеивает дубли, выкидывает мусор, правит, у кого вещь), пишет плашку «что изменилось» под постом, относит место к району карты, ведёт шкалы доверия/близости/напряжения, тайны и названия глав. Всё можно откатить.
- **Один чат — много комнат.** Чат режется на главы по месту из Horae, но только на экране: модель по-прежнему видит всю историю. Полоса сверху листает главы, ≡ показывает весь чат.
- **Атлас карт.** Своя карта у каждого района/города/страны. Карта рисуется (через Гардероб → SLAY) сразу с известными местами по углам — метки встают сами; новое место дорисовывается на ту же карту. Внутри мест — свои планы с комнатами («Квартира·Кухня»). «Отправиться» ставит в чат скрытую отметку новой главы с местом для Horae, а модель на один ответ получает короткую заметку о переходе.
- **Персонаж.** Гардероб (образ целиком — «Примерить»), Вещи с карточками, Гараж (Поехать / Сцена в машине), Отношения (шкалы, моменты, тайны).
- **Сцена / Режиссёр / Память мира.** Кадр главы, последний пост, плашка Летописца; время, погода и тон на следующий ответ; лента событий, «Перейти к утру».

## Установка

```
docker exec sillytavern sh -c 'cd /home/node/app/data/default-user/extensions && git clone https://github.com/clarawill137/LIFE life'
```

Обновление:

```
docker exec sillytavern sh -c 'cd /home/node/app/data/default-user/extensions/life && git pull'
```

После установки или обновления перезагрузи таверну.

## Команды

- `/life` — открыть хаб (`/life map`, `/life person`, `/life world`)
- `/life all` — показать весь чат без деления на главы
- `/life chron` — прогнать Летописца по последнему посту
- `/life off` / `/life on` — аварийно выключить или включить всё

Если что-то совсем сломалось: `/life off` или удалить папку `extensions/life`.
